# BMet Prayer Web

A simple and modern Islamic prayer timetable website designed to help students and staff easily view daily prayer times.

## Live Website

https://20rajonadil.github.io/BMet-Prayer-web/Adil.Talha.html

## Features

* Daily prayer timetable
* Clean and easy-to-read interface
* Mobile-friendly design
* Fast and lightweight
* Suitable for schools, colleges, mosques, and community use
* Accessible from any modern web browser

## Purpose

BMet Prayer Web was created to provide a simple way for students and staff to access prayer times throughout the day. The project focuses on usability, accessibility, and a distraction-free experience.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* GitHub Pages

## How to Use

1. Visit the live website.
2. View the prayer timetable.
3. Check prayer times throughout the day.
4. Access the website from desktop, tablet, or mobile devices.

## Installation

Clone the repository:

```bash
git clone https://github.com/20RajonAdil/BMet-Prayer-web.git
```

Open the project folder and launch:

```text
Adil.Talha.html
```

in your preferred web browser.
